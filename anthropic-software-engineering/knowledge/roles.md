# Anthropic software engineering roles

Last verified: 2026-08-02, live on `https://job-boards.greenhouse.io/anthropic`.

## Allowed title patterns

Roles under the board's "AI Research & Engineering" and "Applied AI"
sections whose title is a software/infrastructure engineering role, not a
research-scientist role. Observed examples at verification time (not
exhaustive — match the pattern, not this literal list):

- Performance Engineer / Performance Engineer, GPU
- Software Engineer, Human Data Interface
- Software Engineer, Research Infrastructure
- Software Engineer, RL Data
- Senior+ Software Engineer, Research Tools
- Staff Software Engineer, Code RL
- Staff Software Engineer, Environments Infrastructure
- Staff+ Software Engineer, Account Compromise
- Staff+ Software Engineer, Safeguards / Safeguards ML Infrastructure /
  Safeguards Review Tooling
- Research Engineer, <team> — engineering-flavored variants (Agents, Code RL,
  Computer Use, Knowledge Team, Pretraining, Visual Knowledge Work): these
  build ML infrastructure and tooling, not primarily conduct research — treat
  as `match`. A "Research Engineer" posting whose team name reads as pure
  research (Interpretability, Life Sciences, Universes) needs judgment — route
  to `review`.

## Route to review, not auto-match

- "Anthropic Fellows Program" and its variants (AI Safety, AI Security, ML
  Systems & Performance, Reinforcement Learning, The Anthropic Institute) —
  a fixed-term fellowship/mentorship track, not a standard engineering hire.
- Any "Research Engineer" or "Research Scientist" posting whose team name
  signals pure research rather than infrastructure/tooling.

## Reject

- Non-engineering functions on the same board: policy, comms, legal,
  recruiting, go-to-market, business operations, and similar.
- Any posting not hosted at `job-boards.greenhouse.io/anthropic`.

## Locations

Most postings list multiple offices (San Francisco, CA; New York City, NY;
Seattle, WA are the most common combination) or are explicitly
Remote-Friendly (sometimes travel-required) — treat any listed location as
satisfying the configured target-location constraint if the posting is
otherwise eligible. Some roles are London, UK only.

No bot-check (Cloudflare, CAPTCHA, or similar) was observed on this board at
verification time — it is a standard Greenhouse-hosted listing.
