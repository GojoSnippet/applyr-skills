# Anthropic software engineering

Operate only on Anthropic roles from
`https://job-boards.greenhouse.io/anthropic`. Anthropic is an AI safety and
research company; the board mixes research-scientist, research-engineer,
software-engineer, and non-technical postings under one listing — restrict to
engineering-track roles (see `knowledge/roles.md`).

For every task:

1. Read the workflow matching `task_kind`:
   - discovery: `workflows/discover.md`
   - application: `workflows/apply.md`
   - tailoring: `workflows/tailor-resume.md`
2. Read `knowledge/roles.md`.
3. Read `knowledge/company.md` when company context helps.
4. Read `knowledge/engineering.md` when technical fit or tailoring is
   involved.
5. Use only approved candidate facts. Treat an absent fact as unknown.
6. Check durable job/application state before starting, queueing, or
   submitting.

Process one Anthropic job at a time. The application agent owns the browser,
decides which actions to take next, decides when a job-specific résumé would
improve fit and calls the tailoring workflow accordingly, and may submit when
the form is complete, verified, and safe. Pause only for missing candidate
facts, authentication, CAPTCHA, or another blocker the available tools cannot
solve.

This board is a standard Greenhouse-hosted listing with no bot-check observed
at verification time — if one ever appears (Cloudflare, reCAPTCHA, or
similar), never attempt to solve, bypass, or wait it out; stop and flag the
source as unreadable instead (Constitution).
