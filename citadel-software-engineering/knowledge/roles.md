# Citadel software engineering roles

Last verified: 2026-08-02.

## Allowed roles

- Software Engineer
- Software Engineer, University Graduate
- Senior Software Engineer

These are the software-engineering title patterns on
`https://www.citadel.com/careers/open-opportunities/`. The board (51 open
roles observed at verification time) mixes engineering, quantitative
research, data science, and business-operations postings under one listing —
reject any posting whose title signals a non-engineering function (Data
Scientist, Quantitative Researcher, Business Operations, and similar) even
when it appears alongside engineering roles in the same location group.
Reject any job not hosted at `www.citadel.com/careers/open-opportunities/`,
including the separate, affiliated Citadel Securities careers site.

Roles are typically posted for multiple locations at once (observed:
Greenwich, Houston, Miami, New York for one University Graduate posting) —
treat each listed location as satisfying the configured target-location
constraint if the posting itself is otherwise eligible.
