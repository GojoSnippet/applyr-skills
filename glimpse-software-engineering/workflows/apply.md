# Apply to one Glimpse role

Read `knowledge/roles.md` and `knowledge/company.md`. Open only the canonical job
URL supplied by the job record.

1. Check shared database state. Stop if this job was already submitted or another
   application for the same job is active.
2. Observe the page before acting and verify each field after writing.
3. Use approved My file answers for identity, contact, eligibility, logistics,
   and reusable questions.
4. Call the Tailoring Agent when a job-specific résumé would improve fit. Use
   the compiled PDF it returns.
5. Draft free-text answers from approved candidate evidence plus the confirmed
   company and role context. Do not invent experience, metrics, authorization,
   location, or motivation.
6. Pause and ask the user only when a required candidate fact is missing, a
   login/OTP is required, or a CAPTCHA appears.
7. Re-read the completed form, uploads, role, company, and canonical URL.
8. Submit with `submit_application` when complete. Record durable confirmation
   evidence before reporting success.

Never use LinkedIn, bypass a CAPTCHA, apply to a different employer, or submit a
duplicate.
