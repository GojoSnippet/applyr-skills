# UpDoc engineering context

Last verified: 2026-07-29.

UpDoc's Ashby board currently lists two fully remote, full-time senior
engineering postings in scope for this skill:

- Senior Software Engineer — published 2026-07-22.
- Senior Software Engineer, AI — published 2026-07-14.

## Shared signals

Both postings share these signals:

- Python as the primary backend language, with comfort in type-hinted,
  modern Python.
- FastAPI and Pydantic for backend services.
- Cloud platform experience, especially Azure, plus containerization and
  DevOps/IaC practices.
- RESTful API design and backend fundamentals (networking, HTTP, caching,
  database design, RPC).
- Healthcare industry standards and regulations — FHIR, HIPAA, and SOC 2 —
  listed as "highly desired," not required.
- Comfort in an early-stage (fewer than 20 employees) startup environment
  with end-to-end project ownership.
- Collaboration with clinical experts to validate accuracy and reliability.

## Senior Software Engineer specifics

- 5+ years of professional backend development experience.
- Designs internal and external APIs powering the UpDoc platform.
- Builds and maintains integrations with third-party healthcare services.
- Touches the end-to-end stack: DevOps, CI/CD, observability, code review,
  production troubleshooting.

## Senior Software Engineer, AI specifics

- 5+ years of professional software development experience, including 2+
  years of backend web development.
- 2+ years building end-to-end LLM applications (personally or
  professionally): production LLM integration/optimization, evaluation
  frameworks, MLOps/LLMOps practice, building AI infrastructure from 0 to 1.
- Leads development of UpDoc's patient-facing conversational agent: a
  scalable, low-latency voice/multimodal system, prompt engineering process
  and evaluation metrics, data pipelines for fine-tuning experimentation, and
  working with backend engineers to deploy models and chat/voice APIs.
- Fine-tuning/alignment experience is a plus, not a requirement.

## Context, not a target role

TypeScript, CapacitorJS, Kotlin, and Swift. This is useful company context but
must not be attributed to either target Senior Software Engineer role unless
