- 5+ years of professional backend development experience;
- comfort with type-hinted, modern Python;
- backend fundamentals: networking, HTTP, caching, database design, RPC;
- experience with cloud platforms (especially Azure), DevOps/IaC, and
  containerization;
- RESTful API design and extensive software testing experience;
- production troubleshooting and end-to-end project ownership;
- highly desired: deep Python/FastAPI/Pydantic experience, FHIR/HIPAA/SOC 2
