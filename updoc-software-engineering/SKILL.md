# UpDoc software engineering

Operate only on UpDoc roles from `https://jobs.ashbyhq.com/updoc`. Reject
similarly named employers, including the unrelated telehealth apps at
`updoc.co.uk` and the Australian "Up Doc" platform, and the unrelated "UpDoc
Media" brand. Target only Senior Software Engineer and Senior Software
Engineer, AI work.

For every task:

1. Read the workflow matching `task_kind`:
   - discovery: `workflows/discover.md`
   - application: `workflows/apply.md`
   - tailoring: `workflows/tailor-resume.md`
2. Read `knowledge/roles.md`.
3. Read `knowledge/company.md` when company context helps.
4. Read `knowledge/engineering.md` when technical fit or tailoring is involved.
5. Use only approved candidate facts. Treat an absent fact as unknown.
6. Check durable job/application state before starting, queueing, or
   submitting.

Process one UpDoc job at a time. The application agent owns the browser,
decides which actions to take next, decides when a job-specific résumé would
improve fit and calls the tailoring workflow accordingly, and may submit when
the form is complete, verified, and safe. Pause only for missing candidate
facts, authentication, CAPTCHA, or another blocker the available tools cannot
solve.
